# Мои заявки

Приложение для телефона (Android): заявки, отчёты по выездам, расходы и заработок за месяц.
Работает без интернета, а когда связь появляется, само отправляет всё на Яндекс Диск.

## Что умеет

- **Заявки**: телефон, имя, адрес, техника, модель, проблема и время выезда. Из заявки можно сразу позвонить или открыть маршрут в Яндекс Картах.
- **Закрытие заявки**: сколько взял, расходы по пунктам (есть кнопки «Компрессор», «Фреон» и т. д.), сразу считается, сколько вышло чистыми. Фото договора и деталей сжимаются до ~300–500 КБ.
- **Расходы не по заявкам**: реклама, бензин, инструмент, связь.
- **Отчёт за месяц**: выручка, запчасти, общие расходы, прибыль, средний чек, разбивка по технике, график за полгода.
- **Поиск** по имени, телефону, адресу и номеру заявки.
- **Подсказки адреса без интернета**: улицы и дома Уфы и Уфимского района плюс квартиры, где уже были
  (с кнопками «Новая заявка» и «Как гарантия»). Любую улицу и дом можно написать руками.
  Справочник `streets.json` собирается из ГАР ФНС (Государственный адресный реестр, открытые данные) и дополняется
  OpenStreetMap (© участники OpenStreetMap, ODbL; снимок в `tools/streets_osm.json`). Обновить базу на сайте:
  ```
  python -I tools/gar_remote.py get 02 .claude/gar        # только файлы Башкортостана, ~230 МБ из архива ~58 ГБ
  python -I tools/build_streets_gar.py .claude/gar tools/streets_osm.json streets.json
  ```
  затем закоммитить `streets.json`. Это же раз в месяц делает сам компьютер мастера: задача Планировщика Windows
  «Справочник улиц» запускает `tools/streets_auto.py` в отдельной копии проекта (`%USERPROFILE%\.zayavki-streets\repo`)
  и отправляет `streets.json`, только если у ФНС база новее и справочник прошёл проверку. Журнал: `%USERPROFILE%\.zayavki-streets\log.txt`.
  На GitHub так сделать нельзя: сайт ФНС не отвечает зарубежным серверам.
  В приложении: «Настройки» → «Справочник улиц» → «Проверить обновление справочника».
  Старая сборка только из OSM: `tools/overpass_fetch.py`, `tools/build_streets.py`.
- **Подъезд и этаж по квартире**: рядом с адресом появляется подсказка для пустых полей. Она применяется по кнопке.
  Офлайн-источники: `entrances.json` даёт подъезд по однозначному диапазону квартир в OpenStreetMap, прошлые заявки
  дают подъезд и этаж той же квартиры или оценку по двум соседним квартирам, если их данные совпадают.
  Обновить карту подъездов:
  `python -I tools/build_entrances_osm.py entrances.json`, затем закоммитить `entrances.json`.
- **Импорт из Telegram** сделан один раз и с версии 1.25 из приложения убран. Если к старым заявкам не дошли фото,
  на странице «Настройки» появляется карточка «Фото из Telegram» для догрузки архива. Скрипт `tools/tg_import.py` остался.
  Папки `telegram/` и `импорт/` с данными клиентов в Git не попадают.
- **Клиент уже был**: при вводе знакомого телефона приложение предлагает подставить имя и адрес.
- **Шифрование**: всё, что уходит с телефона, шифруется паролем мастера (AES-256). Пароль нигде не хранится.
  Без пароля приложение ничего не отправляет на Диск.
- **Яндекс Диск**: в папке «Приложения / Мои заявки» лежат только зашифрованные файлы: `data.bin` (все заявки и расходы)
  и `Фото/<случайный номер>.bin`, а также папка `История` — прошлые копии `data.bin` (по одной в день, последние 10).
  Удалённое фото стирается с Диска через 14 дней, чтобы прошлые копии могли его открыть. В названиях нет имён и адресов клиентов. Открыть их можно только в приложении с паролем.
- **Копия файлом**: кнопка «Отправить копию…» отправляет зашифрованный `.txt`, например себе в Telegram.
  При восстановлении из файла подходит также `.bin` из папки «История». Снимки, которые ещё не отправились на Диск,
  входят в отдельную копию телефона и в копию файлом.
- **Таблица для Excel** скачивается только после ввода пароля. Сам файл не шифруется и сохраняется только в телефон.

## Куда уходят данные

| Куда | Что | Когда |
|---|---|---|
| Яндекс Диск | только зашифрованное | после того как задан пароль и подключён Диск |
| Яндекс Карты | адрес одной заявки | только по кнопке «Маршрут» |
| Яндекс Облако (распознавание) | фото шильдика целиком, без места съёмки | по кнопке «Считать модель» — одно фото; при добавлении фото в заявку без модели — фото, которые телефон сам счёл шильдиком. Фото, где он разглядел договор, адрес, имя с отчеством или номер телефона, не отправляются. Фильтр снижает риск, но не исключает его: телефон читает фото не идеально |
| Telegram и др. | зашифрованный файл копии | только по кнопке «Отправить копию…» |
| GitHub | ничего из данных | там лежит только код приложения |

Если пароль забыт, копию на Диске и в файлах восстановить нельзя. Данные в самом телефоне остаются.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html`, `assets/css/style.css`, `assets/js/app.js` | экраны приложения |
| `assets/js/db.js`, `assets/js/crypto.js`, `assets/js/sync.js` | хранение, шифрование и отправка данных на Яндекс Диск |
| `assets/js/addr.js`, `streets.json`, `entrances.json` | подсказки адресов и подъездов |
| `assets/js/ocr.js`, `assets/js/parse.js`, `vendor/ocr/` | распознавание шильдиков и разбор текста заявок |

| `manifest.webmanifest`, `icons/` | установка на телефон иконкой |
| `version.json` | версия приложения и описание обновления |
| `tools/` | сборка справочников и импорт из Telegram |

## Как запустить на телефоне

Приложение нужно один раз выложить на любой адрес с `https://`. Потом на телефоне откройте этот адрес в Chrome
и выберите «⋮ → Добавить на главный экран / Установить приложение». После установки интернет для работы не нужен.

## Как подключить Яндекс Диск

В приложении: вкладка **«Настройки»**, карточка «Яндекс Диск», там пошаговая инструкция. Коротко:

1. Задайте пароль для шифрования.
2. Зайдите на oauth.yandex.ru/client/new и выберите тип «Для доступа к API или отладки».
3. Название «Мои заявки», доступ «Доступ к папке приложения на Диске» (`cloud_api:disk.app_folder`; найти: напечатать «папке» в поле доступа). Не `yadisk:disk`: с ним Яндекс отвечает Forbidden. Адрес возврата не меняйте.
4. Скопируйте ClientID в приложение и нажмите «Получить ключ доступа».
5. Яндекс покажет ключ на своей странице: скопируйте его в приложение и нажмите «Подключить».

Доступ даётся только к своей папке приложения: остальной Диск приложение не видит.

## Проверено

- Создание заявки, закрытие с расходами, фото, расход, отчёт за месяц: суммы считаются верно.
- Без сервера и сети приложение открывается из памяти телефона, данные на месте.
- Отправка на Диск проверена на подставном сервере. Уходят только зашифрованные `data.bin` и фото, а в файлах нет ни имени, ни телефона, ни адреса клиента. Без пароля не уходит ничего. Без связи всё ждёт и отправляется позже.
- Восстановление с Диска и из файла на «новом телефоне»: неверный пароль не подходит, верный открывает копию. Фото скачиваются с Диска и расшифровываются.
- С настоящим Яндекс Диском с телефона: `data.bin` и зашифрованные фото появились в папке «Приложения / Мои заявки».

## Выпуск новой версии

1. Поменять номер в трёх местах: `APP_VERSION` в `assets/js/app.js`, `version.json` (там же короткое описание) и `CACHE` в `sw.js`.
2. Отправить в `main`. Через минуту у мастера сверху появится полоска «Доступна новая версия — Обновить».
   Вручную: вкладка «Настройки» → «Приложение» → «Проверить обновление».
